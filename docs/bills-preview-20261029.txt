本輪功能
1. 明確填寫應繳 0 元可以新增或儲存；留空、負數與無效數字仍拒絕。
2. 金額 0 且資料完整的帳單顯示本期免繳，不提供付款或標記已繳操作。
   未填資料仍保留待填狀態。付款金額仍須大於 0，不建立任何 0 元付款或記帳紀錄。
3. 每期帳單備註獨立保存，可換行、可清空，最多 2000 字；不同於付款寫入記帳的 note。
   API 更新省略 note 時不清除舊值，清空才保存 null；清單、明細、手動新增均支援。
4. 所有帳單名稱可點開；已繳帳單新增查看明細，列出應繳、已付、待付、帳期、到期日、
   繳費日期與繳款方式。舊資料未記錄日期則如實顯示未記錄，不推測或補造。
   已繳帳單金額／日期僅供閱讀，儲存只改備註，絕不重複付款。
