# 記帳設定：第一批 UI 隔離預覽驗收

日期：2026-09-25。基準提交：6b26dce。

## 範圍
使用實際四個設定頁元件與既有側欄，在獨立 Vite 入口載入。
測試資料與登入替身均為本機記憶體資料，沒有正式憑證；不部署、不推送。
本輪新增預覽工具與截圖，未修改正式頁面邏輯。

agent-browser errors 無回報錯誤，無框架錯誤遮罩。
已目視檢查主要欄位、手機分類底部、付款人改名彈窗與側欄展開畫面。

## 已操作驗證
- 四個設定頁載入；既有分類、排序、狀態與操作按鈕顯示。
- 付款人改名彈窗開啟與取消。
- 手機「更多」展開側欄。
- 店家名稱清空後離開欄位：顯示「請輸入店家名稱」，aria-invalid=true。
- 空白名稱未送出 PATCH；頁面記錄僅有測試 GET，外部資源請求清單為空。

## 不列為已驗收的項目
- 正式登入、資料庫寫入、拖曳儲存及完整 CRUD 回歸：本輪沒有測試。
- 真實手機鍵盤、安全區及真機觸控：本輪為桌面瀏覽器 viewport 模擬。
- 側欄貓咪、品牌圖示及全部設計稿風格：尚未實作，這不是全站改版定稿。
- 手機／平板仍保留原有緊湊標題列，彈窗仍使用原共用樣式；後續要統一。
- 原有樣式仍使部分按鈕顏色不同，留待使用者確認試改方向後統一。
