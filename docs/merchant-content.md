# 店家選單與消費內容

- 記帳新增／編輯的「店家／對象」可以搜尋、新增及管理名稱；空白仍可儲存。
- 初始店家：蝦皮、momo、PChome、全聯、7-ELEVEN、全家。
- 店家更名、停用及重新啟用僅影響選單；歷史記帳使用當時的文字快照，不會連動修改。
- 舊「店家@商品」字串不自動拆分；編輯時可選擇保留原值。
- 消費內容為獨立選填欄位，最多 1000 個字；備註、付款與拆帳計算維持原樣。
- 財務儀表板可搜尋消費內容，下載完整記帳 CSV 包含獨立欄位。JSON 備份也包含此欄位及店家清單。

## 相容與發布

先執行 20260831073253_ledger_merchant_content.sql，再部署網站。舊 RPC 保留，既有帳單付款不受影響；舊客戶端 PATCH 沒傳新欄位時不會清空內容。新 RPC 在同一交易內儲存，保留已結清帳目保護。

回退程式版本不需刪除新欄位或資料表，避免遺失新輸入內容。
